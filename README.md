# Data Science & Programming Portfolio -Phase I

Welcome to my portfolio! This repository contains a collection of projects completed during my Data Science Bootcamp. These projects demonstrate my progression from fundamental Python programming to advanced data manipulation and database querying.

## 📂 Project Overview

### 1. SQL Business Analysis (`/01_SQL_Business_Analysis`)
* **Objective:** Practiced advanced SQL queries using a commercial database schema (Orders, Customers, Products).
* **Key Skills:** Joins, Aggregations, Filtering, and Subqueries for business decision-making.

### 2. Python Fundamentals (`/02_Python_Fundamentals`)
* **Workshop:** A functional calculator app demonstrating user input handling and arithmetic logic.
* **Data Structures:** Practical implementation of algorithms using lists, dictionaries, and tuples.

### 3. Object-Oriented Programming: Bank Account (`/03_OOP_Banking_System`)
* **Objective:** Developed a Python class `Account` to simulate banking operations.
* **Key Skills:** Encapsulation, Class Methods (Deposit/Withdraw), and state management in Python.

### 4. Student Grading with NumPy (`/04_Numpy_Student_Grading`)
* **Objective:** Built a program to calculate grades, totals, and percentages for a student body.
* **Key Skills:** Vectorized operations with NumPy arrays and tabular data formatting.
